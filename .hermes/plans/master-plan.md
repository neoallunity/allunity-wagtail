# Проектный план: allunity-wagtail
## Цель
Полная копия `https://allunity.ru/` на Wagtail CMS (`https://allunity.codered.cloud/`) с улучшенным внешним видом, реальным контентом и рабочим администрированием.

---

## Текущее состояние
- Wagtail 5.2 развёрнут на CodeRed Cloud (allunity.codered.cloud)
- Автодеплой настроен: push в `main` → GitHub Actions → `cr deploy allunity`
- 12 пользовательских секций работают: `/`, `/codex/`, `/news/`, `/projects/`, `/manifest/`, `/institute/`, `/search/`, `/dictionary/`, `/history/`, `/school/`, `/emblem/`, `/discussions/`, `/journal/`, `/library/`
- Контент засижен тестовыми данными через миграции
- **Проблемы**: конфликты миграций на проде, старый контент на главной, нет суперпользователя

## Риски и митигации

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Прод-БД недоступна для миграций | Высокая | Высокое | Использовать `post_migrate` signal вместо data migrations |
| Контент allunity.ru защищён парсером | Средняя | Среднее | Использовать Wayback Machine / ручной ввод |
| CodeRed падает во время деплоя | Низкая | Высокое | Тестировать на staging, иметь бэкап |
| Миграции ломают prod | Высокая | Высокое | Тестировать на копии БД перед деплоем |
| Не хватает прав в CodeRed | Низкая | Среднее | Использовать GitHub Actions + `cr deploy` |
